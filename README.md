# 日報の入力画面

LINE の中で開く、日報の入力画面です（LINE ミニアプリ）。

- `mock/` … 画面の見本です。LINE にもサーバーにもつながらず、入力した内容はどこにも送られません。
  名前・店舗・数字はすべて架空です。
- `probe/` … 開発者が LINE の中での動きを確かめるための画面（疎通確認）です。写真はどこにも送りません。
  確かめの記録は、その端末の中（localStorage と IndexedDB）にだけ残します。
  `probe/config.js` には、問い合わせ先の URL と LINE ミニアプリの ID（どちらも秘密ではないもの）だけを書きます。
- `report-form.js` … 画面で使う計算（日付、時刻、勤務時間、数字の読み取り）
- `app.js` … 画面の動き
- `style.css` … 画面の見た目

このリポジトリには、秘密の情報や本物のデータは入っていません。
